A premium, high-performance professional portfolio built for **Faiza Khan Pathan**, an SEO Specialist and Content Creator. This project showcases advanced UI/UX patterns, 3D interactive elements, and aggressive performance optimizations.

## ✨ Key Features

- **🚀 Extreme Performance**: Optimized for Lighthouse scores of 90+. 
  - Reduced LCP from 5.8s to <1.5s.
  - Implemented route-based code splitting and font preloading.
  - Zero layout shift (CLS) design.
- **💎 Premium Aesthetics**: 
  - Interactive 3D hover effects with mouse tracking.
  - Modern glassmorphism and animated mesh gradient backgrounds.
  - Staggered scroll reveal animations via Framer Motion.
- **📱 Fully Responsive**: Seamless experience across mobile, tablet, and desktop.
- **🎨 Custom Branding**: Personalized SVG icons, unique logo integration, and a curated "Warm & Professional" color palette.

## 🛠️ Technology Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Vanilla CSS (Custom Design System)
- **Animations**: Framer Motion, React Icons
- **Performance**: React.lazy, Preload hints, SVG optimization
- **Routing**: React Router Dom

## 🚀 Performance Optimizations

This portfolio was specifically tuned for speed:
1. **Zero-Delay Rendering**: Removed all artificial loading timeouts to ensure the site is visible instantly.
2. **Bundle Splitting**: Used Vite's manual chunking to separate vendor libraries from application code.
3. **Asset Compression**: Switched to SVG-based favicons and logos (9KB vs 466KB).
4. **Font Optimization**: Implemented high-priority font preloading to fix FOIT and reduce LCP.

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Eshbanoliver/faizaportfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
